# Student Grade Analysis (Learning Project)

This repository is a learning and practice project for data analysis. The goal is to explore and understand which factors are associated with students' final math grades using basic EDA, visualization, and simple statistical tests.

## Objectives
- Practice data cleaning and exploration with pandas.
- Build intuition with visualizations (histogram, boxplot, scatter, heatmap).
- Apply simple statistical tests (t-test, ANOVA).
- Summarize findings in a clear, structured report.

## Folder Structure
```

│  
├─ student.txt
└─ README.md
```

## Notes
- `student.txt` contains the dataset attribute descriptions.
- The notebook `notebooks/student_math.ipynb` focuses on the math dataset.

## How to Use
1. Open the notebook in `notebooks/`.
2. Run cells from top to bottom.
3. Read the markdown cells for explanations and insights.

## Getting Started
### Requirements
- Python 3.10+ recommended
- Jupyter Notebook or VS Code with the Jupyter extension

### Install Dependencies
```bash
pip install pandas numpy matplotlib seaborn scipy scikit-learn
```

### Run
1. Start Jupyter or open the notebook in VS Code.
2. Select your Python environment.
3. Run all cells in order.
